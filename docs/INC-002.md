# INC-DEMO-002 — Timeout

**Тип:** симулированный инцидент  
**Среда:** localhost:8080, demo_service.py

## Симптом
Порт открыт, но HTTP-запрос превышает ожидание клиента.

## Воспроизведение
1. Запустить: python3 demo_service.py --mode slow
2. Выполнить: curl --max-time 2 -i http://127.0.0.1:8080/health

В этом примере сервер специально ждёт 4 секунды, клиент — 2 секунды.

## Что указать в Jira
Время, длительность, результат curl, влияние, точные шаги, выполненные проверки (без секретов).

## Возможная эскалация
Передать сведения L2. Без данных о ресурсах и логах нельзя утверждать, что причина в сети или CPU.

## Проверка восстановления
Повторить запрос после запуска режима healthy. Должен быть быстрый HTTP 200.
