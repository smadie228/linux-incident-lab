# INC-DEMO-001 — HTTP 503

**Тип:** симулированный инцидент  
**Приоритет:** учебное предположение Medium  
**Среда:** localhost:8080, demo_service.py

## Симптом
GET /health отвечает 503 вместо 200. TCP-порт при этом открыт.

## Воспроизведение
1. Запустить: python3 demo_service.py --mode error
2. Выполнить: curl -i http://127.0.0.1:8080/health

## Что проверять
- ss -lnt — слушается ли порт
- curl -i — какой HTTP-код
- Аргументы запуска процесса и, если есть, логи

## Причина в учебном примере
Режим error намеренно возвращает 503. Это не подтверждение реального сбоя.

## Передача на L2
Описать HTTP-код, время, окружение, условия воспроизведения и уже выполненные проверки. Не перезапускать production-сервисы без согласования.

## Проверка восстановления
Перезапустить демо в режиме healthy, получить HTTP 200.
