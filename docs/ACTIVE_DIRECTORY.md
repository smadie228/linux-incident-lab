# Active Directory: план самостоятельного изучения

Сейчас это план обучения, а не подтверждение опыта работы с корпоративным AD.

- [ ] Домен, контроллер домена, OU, пользователи и группы
- [ ] Локальная и доменная учётная запись
- [ ] Управление тестовыми пользователями и группами
- [ ] Групповые политики (GPO)
- [ ] DNS и связь с Active Directory
- [ ] Блокировки учётных записей, безопасный сброс паролей
- [ ] Основы принципа минимальных привилегий

Практика: отдельная Windows Server VM, тестовый домен и вымышленные пользователи. Не публиковать данные реальных корпоративных учётных записей.

На интервью честно отделять изученную теорию от выполненных лабораторных работ.
